# Spam Email Detection Using Machine Learning

## Project Overview
This project detects whether an email or message is **Spam** or **Not Spam (Ham)** using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## Features
- Predicts whether a message is spam or not spam.
- Uses a trained Machine Learning model.
- Simple user-friendly interface.

## Project Files
- `app.py` – Application interface and prediction.
- `train_model.py` – Trains the Machine Learning model.
- `spam_model.pkl` – Saved trained model.
- `requirements.txt` – Required Python libraries.

## How to Run

1. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:

   ```bash
   streamlit run app.py
   ```

## Machine Learning Algorithm
Multinomial Naive Bayes.
